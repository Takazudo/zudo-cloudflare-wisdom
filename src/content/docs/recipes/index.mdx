- [Reverse Proxy to a Fixed Upstream](./reverse-proxy.mdx) -- header hygiene on both legs, manual redirect rewriting with a cross-request hop cap, an explicit trust-model call on cookies/CSP/HSTS, shared-cache safety, and the workerd Content-Encoding trap
- [Cloudflare Access for Internal Sites](./cloudflare-access.mdx) -- identity-backed perimeter authorization in front of a Worker: account-level setup, Worker-scoped applications that cover workers.dev and previews without a zone, the WebSocket limitation, and reading the caller's identity
- [Worker-Side Image Preprocessing and BlurHash Placeholders](./worker-image-preprocessing-blurhash.mdx) -- a bounded image-ingestion pipeline: validate from headers, scale down through the Images binding before any JavaScript pixel work, a fixed 4×4 BlurHash persisted best-effort as nullable metadata, blob-first/row-last with cleanup, the local-versus-deployed Images gap, the base83 comma pitfall, and a browser contract that never hides an image by default
